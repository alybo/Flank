**Версия 0.9 · macOS 26+**

Утилита macOS, которая убирает выбранное окно за край экрана и возвращает его по наведению — по мотивам Slide Over на iPad. Окно остаётся окном своего приложения; утилита управляет его положением через Accessibility API.

Прототип поддерживает одно конкретное окно у выбранного внешнего края: слева или справа. Окно можно выбрать в меню «Выбрать окно…» или добавить жестом: начните двигать окно, зажмите **Control + Shift** и отпустите над карточкой у выбранного края. После назначения доступно «Отменить» на 8 секунд. Жест ещё требует испытаний на реальных приложениях и с системной раскладкой macOS.

«Скрывать выбранное окно» — пауза с сохранением выбора. Выключите переключатель, чтобы вернуть окно на экран; включите снова, чтобы спрятать то же окно. «Отвязать окно» полностью снимает привязку. Для отвязки жестом раскройте окно и перетащите его с теми же клавишами в область «Отвязать окно»; Escape отменяет действие.
