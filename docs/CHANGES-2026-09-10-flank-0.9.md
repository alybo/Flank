# Flank 0.9 — переименование и подготовка GitHub

По запросу пользователя текущая версия программы получает имя **Flank**, номер **0.9** и предоставленную иконку. Целевой репозиторий: https://github.com/alybo/Flank.

## Что изменено

- `SlideOverTahoe.xcodeproj` → `Flank.xcodeproj`; target, shared scheme, product/module и executable называются Flank. Исходники находятся в `Flank/`; точка входа — `FlankApp.swift`, менеджер и реестр — `FlankManager` / `FlankManagerRegistry`.
- Имя окна настроек, подсказки и сообщения заменены на Flank. В настройках виден номер версии из Info.plist.
- `MARKETING_VERSION = 0.9`, `CURRENT_PROJECT_VERSION = 1`, bundle identifier — `Turbo.Flank` для Debug и Release.
- Пользовательский PNG 1024×1024 импортирован в AppIcon; созданы все 10 вариантов macOS 16–1024 px. Исходный 1024 px вариант сохранён побайтово, меньшие размеры сформированы штатным `sips`. SHA-256 оригинала: `afd64c1e9987968367c374d37a9adb7a55fc938e5f50b0e0ee6584e9ac7cb4bb`.
- Новый bundle ID использует собственные настройки. Если они ещё отсутствуют, SettingsStore переносит JSON прежней программы из домена `Turbo.SlideOverTahoe`. Старый домен не изменяется; AX-привязка не восстанавливается автоматически. macOS может потребовать отдельное разрешение Accessibility для Flank.
- README, текущая концепция, AGENTS и тестовый скрипт используют новое имя/пути. Исторические аудит, CHANGES и протоколы сохраняют прежние имена, чтобы не переписывать историю.
- Добавлен `.gitignore` для локального состояния Xcode, build products и локальных секретов. Локальные xcuserdata не включаются в новую версию дерева проекта.
- Старый remote сохранён как `legacy-slideover`; `origin` указывает на `alybo/Flank`. Работа подготовлена в ветке `codex/flank-0.9`, публикация предназначена для `main` и тега `v0.9`. Старые ветки не сливаются и не удаляются.
