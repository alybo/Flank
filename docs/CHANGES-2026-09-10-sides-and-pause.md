# Выбор стороны, пауза и отвязка — 10.09.2026

## Поведение

Поддерживается одно конкретное окно. В настройках добавлен выбор «Слева / Справа». Область закрепления занимает всю высоту выбранного края; индикатор остаётся по центру вплотную к краю. Контур и индикатор зеркалятся, текст сохраняет обычное направление. Обе панели выезжают из-за выбранного края внутрь экрана за 180 мс; повторные обновления не перезапускают анимацию.

Неочевидные «Правый край» с галочкой и «Вернуть окно и выключить» заменены двумя разными действиями:

| Действие | Результат |
| --- | --- |
| Выключить «Скрывать выбранное окно» | Вернуть окно, остановить скрытие, сохранить конкретную AX-привязку в состоянии `paused` |
| Включить «Скрывать выбранное окно» | Проверить ту же цель и спрятать её снова; положение возврата обновляется по её текущему обычному положению |
| «Отвязать окно» | Вернуть окно и очистить выбор после успеха; на паузе не перемещать уже обычное окно |
| «Повторить возврат» при ошибке | Повторить восстановление с сохранением выбора и паузой скрытия |

Во время паузы пользователь свободно перемещает и меняет размер окна. Смена стороны на паузе не двигает окно. Для активной привязки смена стороны сначала восстанавливает окно с прежнего края, затем скрывает за новым. При отказе возврата сохраняются прежняя сторона, цель и безопасная позиция, автоматические действия отключаются. UI отражает сохранённые настройки, а не неудавшееся пожелание.

Перед возобновлением/сменой стороны контроллер повторно проверяет существование конкретного окна, доступность, fullscreen/minimized и внешний край. Внутренняя граница между мониторами не используется для скрытия. В менеджере дополнительно проверяется доступность выбранной внешней границы перед возобновлением.

## Отвязка жестом

Пользователь подтвердил вариант с перетаскиванием, а не с одним зажатием клавиш:

1. Раскрыть закреплённое окно или использовать его на паузе.
2. Начать двигать его, затем зажать выбранные модификаторы (по умолчанию Control + Shift).
3. У выбранного края появляется «Отвязать окно». Стрелка направлена к центру дисплея: влево для правой области, вправо для левой.
4. Отпустить над областью. Окно возвращается к позиции до жеста, затем снимается привязка.

Для другого окна область по-прежнему предлагает закрепление/замену. Escape, отпускание клавиш до mouseUp или отпускание вне области отменяют действие. Неоднозначные/неподдерживаемые drag отклоняются; кнопка отвязки остаётся альтернативой.

Действие запоминает UUID именно той привязки, которая существовала при начале жеста. Менеджер и контроллер отклоняют устаревшую отвязку после смены цели. Позиция до drag сохраняется и при AX-ошибке возврата, чтобы повторная попытка не возвращала окно к краю.

## Реализация и совместимость

- Один `AppController.edge`, одна `SettingsStore.configuration`. Старый ключ UserDefaults `edge_settings_right` сохранён, чтобы не потерять настройки; имя больше не означает правую сторону. Новое поле `side` по умолчанию `.right`, неизвестное значение также безопасно читается как `.right`.
- `DockState` получил `paused`; пауза и смена стороны сохраняют UUID. Закрытие окна/завершение владельца продолжают отслеживаться на паузе, включая повторную паузу.
- Пауза отменяет анимацию, cursor/inactivity timers и отложенное раскрытие. При выходе/освобождении менеджера уже приостановленное окно не перемещается к устаревшей позиции.
- Undo назначения восстанавливает прежнюю привязку вместе с её стороной и состоянием паузы. Выбор другого окна явно включает скрытие для новой цели.
- `WindowCatalog` фильтрует относительно выбранной стороны; геометрия области, раскрытия и направления анимации обобщена на обе стороны.
- SVG-ассеты сохранены без изменения. Используются обычные SF Symbols `arrow.left` / `arrow.right` для направления закрепления/отвязки.
- Выбор окна по-прежнему живёт только в текущем запуске. Пауза не означает восстановление AX-привязки после перезапуска.

## Проверить в новой сборке

- На отдельном тестовом окне: выбрать левую сторону, закрепить, раскрыть; повторить справа, в том числе сменить сторону при скрытом окне.
- Выключить скрытие, переместить/изменить размер окна, включить снова; раскрытие должно вернуть его к новой позиции.
- Отвязать кнопкой скрытое окно; отвязать уже приостановленное окно — оно не должно прыгать к прежней позиции.
- Повторить отвязку через Control + Shift + drag с обеих сторон; проверить Escape и отпускание вне области. Перетаскивание другого окна должно предлагать закрепление.
- Проверить закрытие выбранного окна на паузе, системную раскладку, Spaces и несколько мониторов. Левый вынос через AX ещё не проверен на реальных сторонних приложениях.
