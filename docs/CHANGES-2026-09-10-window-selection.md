## Реализованное поведение

- «Выбрать окно…» доступно из меню и настроек. Строка соответствует конкретному AX-окну: иконка приложения, заголовок, приложение, экран и размер. Подтверждение — клик или выбор клавиатурой и Enter; Escape закрывает список. Неподдерживаемые окна имеют причину отказа.
- Обычный drag окна → зажать Control + Shift → отпустить над карточкой справа. Карточка 144×170 pt, отступ 36 pt от видимой правой границы, положение по вертикали около курсора. Выбор клавиш: Control + Shift / Command + Shift / Shift; жест выключается отдельно.
- Панель не активируется и не забирает mouseUp у приложения. На время кандидата обычное раскрытие/автоскрытие приостанавливается. Размер должен оставаться прежним, а движение AX-origin — соответствовать движению указателя. Drag содержимого без перемещения окна не подтверждается.
- Escape, потеря клавиш до mouseUp, отпускание вне карточки, смена экрана/приложения, блокировка/сон, AX-ошибка отменяют добавление. Сделанное пользователем обычное перемещение при отмене не откатывается. Watchdog очищает состояние при потерянном mouseUp. После подтверждённого mouseUp отпускание клавиш не отменяет commit.
- До назначения проверяются точная AX-ссылка в списке владельца, роль/подроль, геометрия, возможность движения, minimized/fullscreen. Не используются подбор по центру, focused/first fallback, приватный CGWindowID или заголовок как идентификатор. Старые `AXWindowResolver.swift` и `WindowList.swift` удалены.
- Жест сохраняет frame до перемещения. После mouseUp нужны два устойчивых положения с интервалом 60 мс; ожидание ограничено шестью попытками. Только затем происходит назначение. Для повторного drag уже выбранного окна используются те же правила сохранения безопасной позиции.
- Сначала возвращается прежняя цель; при ошибке она остаётся доступной для повторного возврата, новое окно не перемещается. Назначение из picker и жеста использует один `EdgeController` и один менеджер.
- На 8 секунд появляется «Отменить»; действие также доступно в настройках. Возвращается новая цель, затем при возможности заново привязывается прежнее конкретное окно, с его текущей позицией. Если старое окно пользователь уже переместил, Undo не использует устаревший frame. Если возврат новой цели не удался, до истечения срока можно повторить действие. Настройки, следующее назначение, смена дисплеев, закрытие/раскрытие цели инвалидируют Undo.
- AXObserver отслеживает закрытие и смену заголовка. Резервная проверка раз в 3 с очищает привязку только при `invalidUIElement`; таймаут либо отсутствие окна в `AXWindows` не доказывают его уничтожение. Старое событие закрытия защищено UUID сессии.
- Между запусками окно выбирается заново. Старые `selectedPID/selectedBundleID` читаются для совместимости формата, но не разрешают автоматическое назначение приложения. Нет Screen Recording, миниатюр содержимого, телеметрии или новых разрешений.
- Настройки прокручиваются и ограничены высотой экрана; единицы геометрии подписаны pt. Повторная публикация состояния не пересоздаёт overlay с прежним frame.

## Ограничения первой версии

Жест экспериментален до реальных интеграционных испытаний. Поддерживается только исходный дисплей и внешний правый край; если правее расположен экран с пересечением по вертикали, назначение отклоняется, даже при зазоре между дисплеями. Fullscreen, minimized, нестандартные и исходно частично вынесенные окна отклоняются. Приложение не меняет размер окна.

NSEvent global monitor наблюдает события асинхронно и не подавляет системный tiling. Отступ карточки уменьшает пересечение с краем, но не гарантирует отсутствие конфликта. Отказ распознать неоднозначный drag допустим; альтернативой остаётся picker. macOS или приложение могут ограничить вынос окна за экран — manager проверяет фактическую позицию и сообщает об отказе.

AX-чтение выполняется на main actor с короткими таймаутами (150–200 мс на запрос), drag-геометрия читается не чаще 20 раз/с. В каталоге есть отмена и yield между окнами/приложениями, но это не делает AX полностью неблокирующим: зависшее приложение может задержать UI на несколько запросов. Дальнейшее перенесение AX на сериализованную очередь и бюджетирование обхода требуют измерений.

Список не содержит миниатюр или hover-подсветки: одинаковые заголовки/размеры на одном экране всё ещё неудобно различать. Жест позволяет выбрать такое окно напрямую. Выбранное окно в настройках пока показывается заголовком/именем приложения, без отдельного полного индикатора состояния.

Отключение монитора пока не гарантирует возврат на оставшийся дисплей: жест отменяется, UI предлагает вернуть окно и выбрать заново. Политика восстановления после удаления экрана, Spaces, Stage Manager, сбоя процесса и нескольких целей — следующий этап, не завершённая поддержка.

## Ручная матрица перед выпуском

Использовать только отдельные тестовые окна без несохранённой работы.

1. Два похожих окна одного приложения: picker выбирает именно подтверждённое; заголовок меняется, цель сохраняется; закрытие одного не назначает другое. Повторный запуск не выбирает первое окно.
2. AppKit, Safari, Chrome/Electron: обычный drag, modifier-drag и раскрытие в исходную позицию. Трекпад; быстрое/медленное движение; момент отпускания модификатора до/после mouseUp.
3. Drag текста/файла/вкладки, scrollbar, resize, Escape, отпускание вне зоны, потерянный mouseUp, сон/блокировка, отзыв Accessibility, закрытие кандидата во время ожидания — без случайного назначения.
4. Замена скрытой/видимой цели; отказ возврата старой; ошибка нового hide; Undo, повторная попытка Undo, истечение 8 секунд, закрытая/перемещённая прежняя цель.
5. Native tiling включён/выключен, сторонний оконный менеджер, Shift/Control-click особенности приложений. Системные предпочтения менять только по согласованному тестовому сценарию.
6. Один экран, Retina/масштабирование, разные раскладки дисплеев, межэкранный drag, отключение дисплея, Spaces/fullscreen/Stage Manager. Проверить объяснение отказа и ручной возврат.
7. Клавиатура/VoiceOver: список, Enter/Escape, ошибка назначения, настройки и Undo; маленький экран, длинные/одинаковые/пустые заголовки. Проверить настоящий вид drop-карточки и toast.
